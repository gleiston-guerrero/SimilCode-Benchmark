# Changelog

All notable changes to the **SimilCode Benchmark** dataset are documented in
this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.3.0] — 2026-10-26

Second run: copies rewritten with generative AI and screening-oriented analysis. Version 2.1.0 was not archived on Zenodo, and version 2.2.0 was never released; its changes are included here. See `copias_ia/README_COPIAS_IA.md`.

### Added
- `analisis_tipos_clon.py`, `tipos_clon.csv`, `resultados_tipos_clon.json`: reclassification of the 120 pairs with the clone taxonomy of Roy, Cordy and Koschke (2009) by a deterministic rule (normalised token sequences), and separation of copies (types 1–3) from independent solutions (type 4) with cluster-bootstrap intervals over the 30 reference programs and flag rates at review thresholds.
- Copies rewritten with generative AI: light (`CODE_IAL_*`) and heavy (`CODE_IAI_*`) rewrites generated locally with `qwen2.5-coder:14b` (Ollama), and heavy rewrites generated by commercial models (`CODE_IAP_*`; Gemini 3.1 Pro, DeepSeek-V4-pro and Claude Opus 5). 84 copies kept after compiling and running each copy against its original with three input sets; the copies of the program with random output were reviewed by hand.
- `copias_ia/`: generation, verification, case-building and analysis scripts; rewrite prompts (current version and `prompts_v1/`); generation log with prompt hashes and token counts; raw generator responses, including the refusals of GPT-5.5 (8 of 8 requests) and Claude Opus 5 (3 of 8) listed in `rechazos_ia.csv`; equivalence results.
- Second-run results: `metadata_ia.csv` (114 pairs), `copias_ia/resultados_replicas_ia.csv` (four LLMs, three replicas; 1,366 parsable responses), Moss, JPlag and Dolos outputs on the new cohort (`moss_*_ia.html`, `out_jplag_*_ia/`, `out_dolos_*_ia/`, `copias_ia/baselines_raw_ia.csv`), `copias_ia/resultados_copias_ia.json` and `copias_ia/similitud_tokens_ia.csv`.

### Changed
- `benchmark_replicas.py`: categories `ia_ligera`, `ia_intensa` and `ia_api`; records input and output tokens per call in new result files.
- `baselines.py`: accepts the new categories.
- `ejecutar_moss.sh`: `TRABAJO` and `SUFIJO` can be set from outside so that a second cohort does not overwrite the original reports; follows the redirect of the results URL.
- `README.md`, `CITATION.cff`, `PROTOCOLO_dolos_jplag.md` (removed the `--max-comparisons` option, which JPlag 6.3.0 does not have) and `README_baselines.md` (character encoding repaired) updated.

### Removed
- Files added by mistake in an automatic synchronisation (a document unrelated to the project, a copy of the v1.0.1 Zenodo archive and an empty file).

## [2.1.0] — 2026-10-21

### Added
- `analisis_manuscrito.py`: reproduces every number of the manuscript (Discover Computing, version 13) from the archived files, without API calls.

### Changed
- `README.md` rewritten: documents the replicated 2026 benchmark (`resultados_replicas.csv`), the classical detectors, the Big O validation and the reproduction rules; marks `results_llm_comparison.csv` as legacy.

### Notes

- `README_moss.md` contained the Moss user id in commits ca686f8 to 9d30491 (removed in fe88387). That id must be considered public and a new one requested.

## [1.0.0] — 2026-07-08

Initial public, DOI-minted release of the **SimilCode Benchmark** dataset,
accompanying the manuscript submitted to the *International Journal for
Educational Integrity* (Springer Nature).

### Added
- **Ground-truth dataset** (`metadata.csv`) — 120 test-case pairs (60 C# + 60
  Java), organised in 15 reference groups per language, four similarity
  categories per group (identical, functional, structural, different).
- **Source-code corpus** — 60 C# source files under `csharp/` and 60 Java
  source files under `java/`, all authored by the research team specifically
  for this dataset.
- **Experimental results** (`results_llm_comparison.csv`) — 480 rows recording
  the outcome of a controlled within-subjects evaluation of four commercial
  large language models acting as source-code similarity analysts:
  Claude Opus 4.1 (Anthropic), GPT-5 (OpenAI), Gemini 2.5 Pro (Google), and
  DeepSeek-V3 (DeepSeek). Evaluation campaign conducted between 2025-08-29 and
  2025-09-14.
- **Codebook** (`results_codebook.csv`) — machine-readable variable
  dictionary for the experimental results file.
- **Citation metadata** (`CITATION.cff`) — Citation File Format 1.2.0 record
  with `preferred-citation` pointing to the companion manuscript.
- **Open-data license** (`LICENSE`) — Creative Commons Attribution 4.0
  International (CC BY 4.0).
- **Documentation** (`README.md`) — dataset overview, filename convention,
  variable descriptions, loading example, ethical considerations, and
  citation guidance.

### Notes
- All 120 source files were authored by the research team; no file is
  derived from an authentic student submission and no personal data is
  contained in the dataset.
- The dataset is designed as a screening-aid evaluation resource for
  source-code similarity detection systems and is explicitly not intended
  as an evidentiary instrument for adjudicating academic misconduct.
